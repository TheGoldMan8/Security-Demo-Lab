JavaScript Code Comparison
🔴 Vulnerable Code:
// Raw HTML injected directly
const message = entry.message;
container.innerHTML = message;

Using innerHTML with raw user input allows script execution.

🟢 Secure Code:
// HTML entities are escaped
const message = escapeHtml(entry.message);
container.innerHTML = message;

The escapeHtml() function converts < to &lt;, preventing script execution.
