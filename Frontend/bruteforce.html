Code Comparison
🔴 Vulnerable Route:
// No middleware protection!
app.post('/api/auth/login-vulnerable',
  checkDbConnection,
  (req, res) => {
    // Unlimited attempts allowed
    checkCredentials(req, res);
  }
);
🟢 Secure Route:
const loginRateLimiter = rateLimit({
  windowMs: 60 * 1000,  // 1 minute
  max: 5                // 5 attempts max
});

app.post('/api/auth/login-secure',
  loginRateLimiter,     // Rate limiter!
  checkDbConnection,
  (req, res) => {
    checkCredentials(req, res);
  }
);
